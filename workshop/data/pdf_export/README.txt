tisk_z_tekly/        PDF výkresy tak, jak je Tekla vytiskla do jedné složky.
                     Název souboru: <značka bez tečky> - <název výkresu>[ - <revize>].pdf,
                     např. A3 - PRICLE - A.pdf (výkres A.3, revize A).
                     Značka: A = sestava, P = dílec, G = výkres rozmístění.
seznam_vykresu.csv   seznam výkresů ze seznamu výkresů Tekly (Document manager).
                     Oddělovač středník. Typ: A = sestava, W = dílec, G = rozmístění.
                     Revize = aktuální revize výkresu (prázdná = bez revize).
                     Stav = Aktuální / Neaktuální (model se od tisku změnil).
